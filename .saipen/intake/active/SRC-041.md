==================================================
BLOCKER BEHAVIOR
==================================================

A failing widget or unavailable source does not automatically block the entire SAIHOME.

Prefer graceful degradation.

Examples:
- SAIMAIL API unavailable -> SAIMAIL module unavailable/hidden, Home still works.
- router down -> Home works and reports router degraded.
- quota read fails -> last-known stale value if canonical engine service supports it.
- token telemetry unsupported for one engine -> stats coverage becomes partial.

Hard block only when:
- persisted data would be corrupted;
- navigation/execution semantics become unsafe;
- migration cannot be made safe;
- authoritative source ambiguity could cause false control actions.

Follow the ZAICODE fail-open principle where safe:
if Home can physically and safely open, open it and show the degraded condition.
