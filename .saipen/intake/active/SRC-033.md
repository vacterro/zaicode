Куда бы я смотрел теперь

Первое место: full-system E2E, а не новый UX.

Сценарий должен быть примерно такой:

ZAICODE cold start

→ project detected
→ SAIPEN state projected
→ engine availability loaded
→ START
→ primary session spawned
→ /goal cc all
→ SAIPEN claims Work
→ worker выполняет реальные изменения
→ STATE/BOARD/LOG меняются
→ ZAICODE отражает их live
→ SAIMAIL telegram приходит от другого worker
→ основной worker получает awareness
→ один worker принудительно убивается
→ recovery создаёт следующую generation
→ router кратковременно unavailable
→ backoff/retry
→ ZAICODE restart
→ state восстанавливается
→ Work продолжается
→ VERIFY
→ terminal DONE
→ UI показывает настоящий final state.

Вот этот один test даст тебе больше engineering confidence, чем ещё четыре wave UI features.
