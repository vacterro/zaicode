# Установка ZAICODE

ZAICODE — это три проекта, работающих как один: приложение ZAICODE, SAIPEN
(протокол, который держит работу агентов под контролем) и SAIMAIL (почта, которой
агенты пользуются, чтобы сообщать друг другу новости). Установка вручную означает
три клона, инструменты Node.js, окружение Python и сборку. Установщик делает всё
это: запустите его, подождите — и ярлык ZAICODE окажется на рабочем столе.

## В один клик

- **[ZAICODE-Setup.exe](https://github.com/vacterro/zaicode/raw/master/install/ZAICODE-Setup.exe)**:
  скачайте, дважды щёлкните, нажмите **INSTALL**. Окно (золото на тёмном фоне,
  баннер SAIPEN) показывает каждый шаг по ходу выполнения, прошедшее время и
  по запросу журнал; в конце — **START ZAICODE** либо **TRY AGAIN** /
  **Autotroubleshoot** / **Open log**, если какой-то шаг не завершился. Если
  указать уже существующую папку ZAICODE, кнопка будет называться **UPDATE**:
  тот же запуск обновляет и восстанавливает установку. Exe-файл содержит
  скрипты установки и не требует ничего рядом с собой; он собран
  `install\setup\build.cmd` (компилятором .NET Framework, который есть в любой Windows 10/11).
- `install\Setup-ZAICODE.cmd` (двойной щелчок): та же установка в консоли.
- С нуля, в PowerShell:

  ```powershell
  & ([scriptblock]::Create((irm https://raw.githubusercontent.com/vacterro/zaicode/master/install/Install-ZAICODE.ps1)))
  ```

Параметры установки: `ZAICODE-Setup.exe -InstallDir D:\ZAICODE` (папка по умолчанию),
`/auto` (запускается сразу), `/quiet` (без окна: консольный установщик, код выхода
= результат). Первый запуск собирает приложение на этой машине, это занимает время;
последующие запуски только обновляют и восстанавливают.

## Бесплатные модели, ничего настраивать не нужно

Приложение поставляется со своим 9router. На машине без него ZAICODE запускает его
приватно (изолированный режим, порт 20138), берёт **SAIFREN** из бесплатных
тарифов без ключей и делает `SAIRoute / SAIFREN` моделью для новых задач, так что первая
задача, набранная в «Новая задача», получает ответ: без ключа, без аккаунта, без
настроек. Входы в Claude Code, Codex и Antigravity необязательны; вход, который
не настроен на машине, показывается как «необязательно, войдите в любой момент»,
а не как «требует вас». Проверка: `node packages/desktop/scripts/verify-zaicode-free.cjs <ZAICODE.exe>`
запускает собранное приложение на пустом профиле (собственные HOME, APPDATA и
LOCALAPPDATA) и проходит, только когда роутер изолирован, SAIFREN отвечает на
пробу первого токена, а задача в «Новая задача» получает ответ.

## Обновления: четыре части, один ZAICODE

Рабочее окружение (лаунчер, установщик), приложение, SAIPEN и SAIMAIL — четыре
клона. Каждый обновляется сам: **Настройки -> ZAICODE -> Обновления** перечисляет
их с версией и коммитом, обновляет по одному вручную или все сразу, а также имеет
переключатель «самостоятельно» для каждой части (в установленном ZAICODE включён
по умолчанию, в рабочей копии разработчика выключен). ZAICODE проверяет через
несколько минут после запуска, затем каждые шесть часов. После обновления каждая
часть получает своё: приложение — зависимости (когда `pnpm-lock.yaml` изменился) и новую
сборку (готовится, пока ZAICODE работает, запускается при следующем старте), SAIPEN —
свой лаунчер, SAIMAIL — свою `.venv` установку, рабочее окружение — новый
корневой лаунчер. Клон на другой ветке, с локальными коммитами или с правками,
которые обновление перезаписало бы, попадает в отчёт и остаётся точно как есть.

```powershell
.\install\Update-ZAICODE.ps1                          # everything
.\install\Update-ZAICODE.ps1 -Component saipen        # one part (or "app,saimail")
.\install\Update-ZAICODE.ps1 -Check                   # what is new, change nothing
.\install\Update-ZAICODE.ps1 -Check -Json             # the same for a program
```

## Что делает установщик

Установщик — это проверки Autotroubleshoot, запускаемые с «repair» (восстановление)
в пустой папке, в таком порядке. Каждый шаг идемпотентен, поэтому повторный запуск
обновляет установку и чинит сломанное.

| Проверка | Восстановление |
| ---- | ---- |
| Git, Node.js 24, Python 3.11+ | использует копию на машине, если она подходит; иначе приватную копию в `.tools\` (MinGit из Git for Windows, Node.js 24.14.0 с nodejs.org, Python из его пакета NuGet). Без прав администратора. |
| pnpm | закреплённый pnpm 10.33.2 в `.tools\pnpm10` |
| ZAICODE workspace | клон `vacterro/zaicode`, ветка `master` (исходники лаунчера, установщик, документация; память разработчика `.saipen/` исключается; ветка `workspace` до 2026-09-27) |
| ZAICODE app source | клон ветки `zaicode` в `zcode\` |
| SAIPEN | клон `vacterro/saipen` в `saipen\`; его `bin\saipen.cmd` написан под этот клон и этот Python |
| SAIMAIL | клон `vacterro/saimail` в `saimail\`, установлен в `.venv\` |
| saimail-local | командный клиент SAIMAIL, который используют панели SAIMAIL в ZAICODE (поставляется с SAIMAIL `0.0.2a3`; проверка `saimail-cli` сообщает OK) |
| 9router package | пакет 9router: `9router` из npm в `.tools\router`, встроен, чтобы SAIFREN работал без настройки (WARN, если npm не может его получить) |
| Зависимости приложения | `pnpm install --frozen-lockfile` (снова при изменении `pnpm-lock.yaml`) |
| Сборка приложения | `pnpm bundle:zaicode`; пока ZAICODE работает, новая сборка готовится и подменяется при следующем старте |
| Подмена подготовленной сборки | удаляет `win-unpacked.previous`, оставшийся после сбоя подмены из-за длинного пути, и подставляет ожидающую сборку, пока ZAICODE закрыт |
| Корневой лаунчер | `tools\launcher\build.cmd` -> `ZAICODE.exe` |
| Ярлыки | `ZAICODE` -> `ZAICODE.exe` на рабочем столе и в меню «Пуск» |
| Входы Claude / Codex | только отчёт: каждый вход `~\.claude*` / `~\.codex*` — свой движок в ZAICODE (A1, A2, C1, ...); вход требует вас, в браузере |

Корневой лаунчер указывает ZAICODE на установленный SAIPEN (`saipen\`) и ставит
`.tools\` и `.venv\Scripts` первыми в PATH приложения, так что приложение, его агенты
и воркеры используют установленные копии.

## Несколько подписок

Каждый вход в Claude Code или Codex живёт в своём домашнем каталоге: `~\.claude`,
`~\.claude-account2`, ... и `~\.codex`, `~\.codex-account2`, ... ZAICODE находит
их все. Подготовить больше при установке:

```powershell
.\install\Install-ZAICODE.ps1 -AddClaudeAccounts 1 -AddCodexAccounts 2
```

Установщик создаёт домашние каталоги и печатает точную команду входа для каждого
(`$env:CODEX_HOME = '...'; codex login`). То же самое в ZAICODE: Settings ->
Engines & limits -> добавить ещё один вход.

## Автодиагностика

```powershell
.\install\ZAICODE-Doctor.ps1            # check only; exit 1 while something fails
.\install\ZAICODE-Doctor.ps1 -Repair    # check and repair (install\Doctor.cmd)
.\install\ZAICODE-Doctor.ps1 -Json      # results as JSON
.\install\ZAICODE-Doctor.ps1 -Repair -Only app,launcher
```

Статус каждой проверки: OK, FIXED (было сломано, исправлено), WARN (работает, но чего-то
необязательного не хватает), INFO (нужно вам: вход), FAIL. Логи в
`install\logs\`; сводка последней установки — `install\install-report.json`.
В приложении Router -> Autotroubleshoot чинит работающий роутер и пулы.

## Параметры

| Параметр | По умолчанию | |
| ---- | ---- | ---- |
| `-InstallDir` | `%USERPROFILE%\ZAICODE` | куда всё устанавливается |
| `-ShortcutDir` | Desktop | куда кладётся ярлык ZAICODE |
| `-NoStartMenu`, `-NoShortcut` | | пропустить эти ярлыки |
| `-PortableTools` | | приватные Git / Node.js / Python, даже если они есть в системе |
| `-Launch` | | запустить ZAICODE после установки |
| `-ZaicodeRepo`, `-SaipenRepo`, `-SaimailRepo` | репозитории GitHub | другой источник (форк, локальный клон) |

## Проверка

`install\tests\Test-ZaicodeInstall.ps1 -InstallDir <dir> -ShortcutDir <dir> -Smoke`
проверяет чистую установку, создаёт неисправности (ярлык и лаунчер удалены, лаунчер SAIPEN
указывает на отсутствующий Python, venv у SAIMAIL удалён, node_modules
записан для другого lockfile, остался сборочный каталог глубже MAX_PATH),
проверяет, что доктор находит и чинит каждую, затем запускает цель ярлыка
с изолированным профилем и останавливает ровно то дерево процессов, которое сам запустил.

`install\tests\Test-ZaicodeUpdate.ps1` собирает четыре одноразовых репозитория на
диске и установку их клонов, затем доказывает: проверка ничего не меняет, одна часть
обновляется отдельно со своим продолжением (лаунчер SAIPEN, корневой лаунчер),
пересекающиеся локальные правки и локальные коммиты сохраняются, неизвестное
имя части отклоняется. Без сети.
