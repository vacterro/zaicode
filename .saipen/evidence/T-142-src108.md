## Validation

- `pnpm typecheck`: PASS on the final source tree.
- `pnpm verify:pre-push`: PASS; UI 836, services 92, desktop 200, CLI 40;
  1168 passed, 0 failed, 2 platform skips. Lint has 100 existing warnings and
  no errors; the architecture gate passes with no new violations.
- `pnpm build:zaicode`: PASS on the final implementation.
- Desktop UI acceptance: PASS in both verification and independent review.
  Visible Electron ran the real built renderer and desktop host in a separate
  temporary profile, with updates off and no provider credentials. Only the
  native folder picker was substituted to return two owned temporary projects.
  Settings, project opening, context menus, folding and persistence used real
  clicks and stores. No live profile or running user session was altered.
- START browser acceptance: actual components and existing command-store ports;
  only the file-service owner was substituted with a stable SAIPEN-state fixture.
  This checks routing, not a paid model call.
- Regression controls restore exact pre-fix bytes from Git and run unchanged
  verifiers/fixtures against before and after implementations. Appearance,
  START, collapsed slots, pixel layout and real START clicks each fail before
  and pass after. Digests and command exit codes are in
  `T-142-regression/receipts.json` and `browser-receipts.json`.
- The initial pixel instrument used a fixed 70ms startup delay and failed once
  while the build competed for resources. It was replaced by a condition wait:
  initial layout ≤1000ms, inner resize/mount ≤500ms, below the 1500ms heartbeat.
  The revised unchanged instrument was then re-established red/green.
- Two inherited source-shape assertions were updated: selected-project style
  moved from the clipped inner label to the whole row; folder controls moved
  from the first member to an always-visible strip. Actual UI checks establish
  the new behavioral oracle independently of those assertions.
