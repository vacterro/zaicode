## R002 — composer jitter/blur: DONE (machine-green)

Root cause (proven by the RED control): the fit ladder re-decided from raw
fractional geometry on every ResizeObserver pass against a 0.5px threshold.
With the full-layout overflow hovering near half a pixel, every pass flipped
compact/full — measurement changed state, state changed geometry, geometry
reversed the decision, and the row repainted continuously (the blur).

Fix (stable fit algorithm, no transitions/debounce-cosmetics/blur-removal):

- `packages/ui/src/prompt-editor/composerFitDecision.ts` (new, DOM-free):
  quantize every measurement to whole pixels; decide from the full-layout
  overflow ladder; hysteresis on release only (collapse the moment anything
  overflows; a rung returns only with 8px of slack).
- `packages/ui/src/prompt-editor/useComposerToolbarFit.ts`: uses the decision
  (live collapsed depth is the hysteresis memory), probes at quantized width,
  skips DOM writes when the plan equals the live state (a converged row stops
  touching layout), batches observer callbacks per animation frame. DOM
  contracts kept (`data-composer-compact`, `data-composer-model-icon`,
  `data-composer-provider-compact`, `--composer-model-max-width`); send/cancel
  never collapse; wrap-not-clip fallback kept.
- Test: `packages/ui/test/zaicodeT224ComposerFit.test.ts` — 10/10 green:
  RED replays the old fractional-threshold rule on a wobbling 301px-class
  boundary row and must alternate forever (it does, 10+ transitions);
  GREEN converges from empty and from fully collapsed, holds across wobble
  frames, neighbors stable in 0.5px steps, idempotent, hysteresis band edges,
  collapse never delayed, clamp behavior, and 8 product rows (sidebar
  open/closed left/right, attachment present, SAIFREN present, narrow,
  fractional DPI). Pre-existing strip/extent suites still green (8/8).
