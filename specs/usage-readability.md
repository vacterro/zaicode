# Usage surface ownership and readability

The existing zaicodeUsageSurface(mode, workspaceOwnsPanes) contract owns placement. A global portal renders only the `global` result; a visible workspace owns `page`/`sidebar`. Treating every result except `none` as global mounts both hosts, duplicating the title/actions and reads. Each open view must have one title, one pair of placement/close controls and one reading owner. Closed mode has none. Draft/no-workspace views keep the global portal; active workspace views keep their existing pane. No public routing contract is replaced.

Usage presentation uses the existing UI font scale and inherited interface font, with a larger base table font and caption headers. Metric cells stay on one line. Counts abbreviate to three significant digits with K/M/B/T at large magnitudes; small counts remain integers. Exact counts and positive USD values remain available on hover. Missing/nonfinite/zero cost is one dash; a genuinely positive sub-cent cost remains `<$0.01`. USD estimates are rounded and abbreviated, never a bill. These stateless formatters belong to the existing usage label/presentation module and are shared with the efficiency pane. No persistence, identity, routing or accounting value changes.
