became available. A model saying the controls look correct is insufficient.

the current T-224 packaged evidence.

Boxes. Its existing checklist calls for an effective row setting in both
presentations while ordinary Simple Boxes buttons remain flat. Check that the
control is usable, ON/OFF changes the rendered row edge, ordinary buttons keep

disabled or inert control is a failed outcome, not a skipped case.

the menu disables it when global hard bevels are off, and the appearance owner

single preference. Project that flag independently in product mode; scope row

new preference, migration, timer, geometry adjustment or state writer is added.
