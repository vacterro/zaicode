# ZAICODE 0.0.3

One per-user Windows installer contains ZAICODE, managed SAIPEN and SAIMAIL,
9router_extra 0.5.91-extra and private Python and Git/Bash. A new local mailbox
and the default FREE route initialize automatically. No separate repositories,
global developer tools or runtime installation are needed.

Managed components consume approved stable release manifests with exact sizes
and SHA-256 hashes. Updates stage immutable revisions, preserve user and project
state, retain the previous release and roll back a candidate that cannot start.
Uninstall keeps settings, sessions, projects and mailboxes.

The conversation header offers persistent Compact/Full action visibility:
Full shows every ticked button and menu line at once instead of only the ones
the current moment calls for. Ready SUBSAIPEN packages are counted above the
composer with a Collect button; Collection keeps SAIPEN's canonical admission
by sending `saipen collect <producer>` rather than deciding anything itself.
With the sidebar Auto switch on, a newly ready producer is collected once.
Binary reasoning choices always use the enabled value in ZAICODE. Antigravity
and ZCode subscription windows start eligible five-hour cycles automatically.
Long folder-deletion actions wrap within the confirmation dialog.

Supported targets: Windows 10/11 x64. Optional providers and remote mail peers
can remain unavailable without blocking safe local launch. Unknown mail senders
retain the existing trust and quarantine rules.

Cryptographic release signing is not established. Stable updates use the trusted
repository's HTTPS release manifest and SHA-256 verification.
